A character that has never tried an item at a level rolls from its name on the first attempt, so a name can be picked for a run of first-attempt successes on the selected item from its current level. Only the first attempt per level counts, the character must have crafted the item once before it can upgrade it, and this has not been tried in game.

How this works

Every number here is read from the game's own code and data, not typed in. The item stats, recipes, idols and icons come straight out of the client's asset bundles; the arithmetic is the game's, ported line for line.

  • The roll. When you press upgrade at the Forge of Potential, the game looks up a seed for the pair (item, target level) in your character. If there is none yet, it starts from hash(character name) + hash(item) + level. It seeds Unity's random generator with it, draws one value as the roll, draws once more to store as the slot's next seed, and only then judges the roll. Reloading cannot change it; the next outcome for every slot is already in your save.
  • The outcome. The idol decides: a roll at or below its success chance upgrades the item one level. Otherwise, if the idol's break chance is at or above 1 − roll, the item is destroyed and a share of the recoverable materials comes back; otherwise the item loses a level. Every idol in the game currently has a 65% success chance and a 100% break chance, so a failure always destroys, but the page reads those numbers from the idol rather than assuming them.
  • The cost. Each attempt costs the recipe's per-level amounts for the target level plus one idol, paid whether it succeeds or not. From level 4 up the per-level multiplier grows by a half per level, which is why late upgrades get expensive.
  • The stats. Each stat is its base plus a per-level step times (level − 1), with no cap. The Forge of Potential lets a level go past the item's normal maximum, and the steps just keep adding.
  • The save. The character file is read field by field the way the game reads it, so the inventory, the name, the id and the seed table come from their real places rather than a search for a likely-looking pattern.
